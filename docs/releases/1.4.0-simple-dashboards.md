# 1.4.0 — simpler dashboards and organised source

This release simplifies both role dashboards, shortens payment/deposit instructions, adds phone navigation and groups the source into role and feature folders. Rental components and role dashboards use independent Dart libraries.

Monthly rent remains due on the 1st. A first partial month remains prorated from actual move-in. New tenants' one-off deposit deadline remains ten calendar days from move-in, with existing legacy agreements preserved. Pending payment reports remain separate from confirmed money. Bank transfers still happen outside BackyardPay.

## Upload

1. Download `downloads/BackyardPay-Netlify-web.zip` from this release's GitHub commit.
2. Open the existing Netlify project's overview or Deploys page and drop that ZIP into its deployment area.
3. After publication, reload the site and sign in as each role.

Use `BackyardPay-Netlify-source.zip` for the readable Dart project. No new SQL is needed for this UI release if the previous fixed payment rules are installed. Do not upload the source ZIP to Netlify Drop.

See `docs/design/USABILITY-REVIEW.md` for the slide references and task walkthrough, and `docs/PROJECT-STRUCTURE.md` for the source map.
